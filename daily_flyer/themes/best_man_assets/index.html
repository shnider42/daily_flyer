About privacy & access

The online notebook is protected by your password. Only a salted password hash is stored, not the password itself. Notes are stored in a dedicated database table on Supabase. They are protected by access controls, but are not end-to-end encrypted.

A local safety copy and any recovery copy are stored unencrypted in this browser. Locking the notebook signs this tab out and removes its main local copy. Downloaded backups and recovery copies remain until you remove them or clear website data.

There are no analytics, ads, or third-party fonts. Hosting providers may keep ordinary request logs. Short-lived, hashed connection identifiers are used to limit password guessing.

The address is kept off the project directory and asks search engines not to index it. Anyone with the notebook password can read and edit the same notebook. There is no email recovery; keep the password and a backup somewhere safe.
