Keep edits across Render restarts and deploys

On a paid web service, attach a persistent disk at /var/data, both sports will detect that mount automatically. For another disk location, set YEAR_TWO_DATA_DIR to its directory. Existing sport-specific database variables take precedence. The file must be on that disk; the environment variable alone does not make storage durable. Free Render services cannot attach disks. Automatic browser backups can restore a draft after a server reset. Also export a portable backup before changing storage, then restore and save it afterward. Use a single service instance with its attached disk.
