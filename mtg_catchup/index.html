Three changes to start with. Interactive filters appear when JavaScript is available.

2024-11-14 · Announced

Double-blocking works differently.

Foundations removed the requirement to order blockers for combat damage.

When damage is assigned, you can divide it among blockers without that order or lethal-first requirement.

Official source ↗

2019-06-03 · Announced

A fresh seven, every mulligan.

The London mulligan changed how you replace an opening hand.

Draw seven each time; when you keep, put one card on the bottom of your library for each non-free mulligan.

Official source ↗

2024-10-25 · Announced

The rotation calendar moved.

No Standard rotation in 2026; rotation shifts to the first set of 2027.

The announced calendar moves that reset to the start of the year from 2027.

Official source ↗

What is a format?

The rules for a way of playing, including which cards your deck may contain.

What is rotation?

Older sets leaving a format’s card pool. It is different from banning an individual card.
