# SKYWARD module contract

Shared source: games/skyward/public. ES modules (.mjs). No build; Three.js r160 is vendored at ./vendor/three.module.js. Positive Z forward, Y altitude, X right. Heading 0 points +Z; positive heading turns right; positive pitch is nose UP; positive roll means bank RIGHT. Units meters, seconds, radians, speed meters/second. All ranges and flight performance are game abstractions.

campaign.mjs exports AIRCRAFT (keyed object), MISSIONS (ordered array), getMission(id), getAircraft(id). Mission shape: {id,number,title,year,era,location,aircraft,kind,biome,description,briefing:[strings],lesson,duration,weather:{wind,cloudBase,cloudTop,fog,timeOfDay},start:{x,y,z,heading,speed,airborne},runways:[{x,z,y,length,width,heading,label,carrier}],waypoints:[{x,y,z,radius,label}],enemies:[{id,type,aircraft,x,y,z,heading,speed,health}],targets:[{id,type,x,y,z,health,label}],goal:{...},historicalNote,sources:[urls]}. Root may adjust mission data for gameplay.

Aircraft shape: {id,name,shortName,era,model,color,accent,maxSpeed,cruise,stallSpeed,acceleration,turnRate,climbRate,rollRate,health,gun,missiles,bombs,radar,stealth,vtol,role,summary}. Numeric speeds are simulation m/s.

sim.mjs exports FlightSimulation, terrainHeight(x,z,mission), advancePlayer(player,input,dt,aircraft,mission,settings). new FlightSimulation(mission,settings). .player = {x,y,z,heading,pitch,roll,speed,throttle,health,fuel,gear,flaps,engine,startupStep,onGround,aircraft,verticalSpeed,stalled,ammo,missiles,bombs}. .step(dt,input) input {roll,pitch,yaw,throttle,fire}. .action(name) supports startup,gear,flaps,brake,level,target,missile,payload,countermeasure,radar,hover,abort. .enemies, .targets, .projectiles, .effects, .paratroopers, .waypointIndex, .status ('flying','success','failed'), .objective (string), .hint (string), .progress (0..1), .time, .score, .events (array {id,kind,text}), .targetId, .lockProgress, .radarOn, .threat. .getSnapshot() serializable host world; .applySnapshot(snapshot) for remote coop world excluding own player. .remotePlayers array available for host weapons resolution. .applyRemoteAction(action,player) optional host arbitration.

renderer.mjs exports FlightRenderer. new FlightRenderer(canvas,settings), .loadMission(mission,aircraft), .render(sim,dt,{camera:'chase'|'cockpit'|'cinematic',lookX,lookY,remotePlayers:[]}), .resize(), .setSettings(settings), .project(x,y,z) returns {x,y,visible} screen pixels, .dispose(). .renderMenu(time,aircraft) draws attractive hangar/sky aircraft menu backdrop. Constructor can throw on WebGL unavailability; app supplies readable fallback.

network.mjs exports SquadronClient with constructor({onStatus,onRoster,onStart,onWorld,onAction,onEnd}). .create(name,missionId), .join(code,name), .ready(bool), .start(missionId), .sendPose(player), .sendWorld(snapshot), .sendAction(action), .leave(), .samplePlayers(). Properties .code,.id,.isHost,.connected,.latency,.roster. Callback onStart({missionId,seed}), onWorld(snapshot), onAction({action,playerId,player}), onEnd(message), onStatus(status,message). Local plane simulation remains immediate; remote snapshots interpolate. Server only host can sendWorld/start; members authenticate by reconnect token; bounded four players; no lobby public listing. Root owns UI, controls, audio.
