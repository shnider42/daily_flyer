REPRODUCE / VERIFY / DEPLOY

A separate place to break things.

  1. Capture the problem. Note the request ID, match code, action and approximate time. Download that match’s diagnostic snapshot. It includes both armies and recorded undo/redo results.
  2. Reproduce locally. Import the snapshot into a new disposable database. The importer creates fresh credentials and a different match code. Investigate the copied board and history without issuing orders in the live battle.
  3. Test the fix. Add a regression test, run the suite, then try the UI. Use a separate Render staging service with its own disk only for deployment-specific issues.
  4. Deploy deliberately. Push the verified fix, follow the deploy in Render, then compare the running commit above and check a disposable battle.
python -m ww2_tactics.devtools import dsl-MATCH.json --db instance/repro.sqlite3

The importer prints local MOVE codes and the command to run the copy. Do not upload a diagnostic export to a public issue: it reveals fog-of-war positions. Disk totals describe the database’s filesystem, not player locations.
